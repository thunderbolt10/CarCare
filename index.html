CarCare

CarCare is a personal tool that reads status information (odometer, fuel, tyres, warnings, diagnostics and similar) from the owner's own Volvo car through the Volvo Connected Vehicle API and shows it on the owner's computer.

It only reads data; it sends no commands to the car. No data is stored or shared with anyone else.

The callback page receives the Volvo ID sign-in result.
